# Consumer Review Sentiment Analysis

## What I built

I cleaned product-review text, estimated positive, negative or neutral sentiment with spaCy and spaCyTextBlob, and compared semantic similarity between two reviews.

## Implementation

I wrote the analysis in [semantic_analysis.py](semantic_analysis.py). I used Python and spaCy, pandas and spaCyTextBlob.

## Running my code

Install spaCy, install its `en_core_web_md` English-language model, and run `python semantic_analysis.py`. Supply `Datafiniti_Amazon_Consumer_Reviews_of_Amazon_Products_May19.csv` alongside the script, as that input is not packaged in this project.

HyperionDev task M13T03.
