# Word and Sentence Semantic Similarity

## What I built

I compared word, token and sentence similarity scores with spaCy's vector-based language model.

## Implementation

I wrote the analysis in [semantic-1.py](semantic-1.py). I used Python and spaCy.

## Running my code

Install spaCy, install its `en_core_web_md` English-language model, and run `python semantic-1.py`.
