# Garden-Path Sentence Tokenisation

## What I built

I used spaCy to tokenize garden-path sentences and inspect named entities and their category explanations.

## Implementation

I wrote the analysis in [garden.py](garden.py). I used Python and spaCy.

## Running my code

Install spaCy, install its `en_core_web_sm` English-language model, and run `python garden.py`.
