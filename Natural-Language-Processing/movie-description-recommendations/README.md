# Movie Description Recommendations

## What I built

I compared a sample movie synopsis against other descriptions using spaCy similarity scores to find the closest candidate.

## Implementation

I wrote the analysis in [movies_task.py](movies_task.py). I used Python and spaCy.

## Running my code

Install spaCy, install its `en_core_web_md` English-language model, and run `python movies_task.py`. Supply `movies.txt` alongside the script, as that input is not packaged in this project.
