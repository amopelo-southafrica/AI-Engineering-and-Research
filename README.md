# AI Engineering and Research

I explore how data, machine learning and neural networks can help answer questions in business, economics, finance and computer vision. This repository contains the Python notebooks I developed, with methods and results explained in my own words.

## Machine learning

- [Customer Churn Prediction](Machine-Learning/customer-churn-prediction/) — I trained logistic regression and random forest models to investigate customer retention risk.
- [Ames Housing Price Regression](Machine-Learning/ames-housing-regression/) — I estimated house prices using living area and garage size with multiple linear regression.
- [Hierarchical Clustering](Machine-Learning/hierarchical-clustering/) — I compared distance measures and linkage methods to find groups in Iris measurements.

## Deep learning

- [Fashion-MNIST Image Classification](Deep-Learning/fashion-mnist-classification/) — I trained a PyTorch network to classify clothing images and evaluate its errors.
- [Business Slogan Generation and Classification](Deep-Learning/neural-network-nlp-capstone/) — I used recurrent neural networks to generate industry-specific slogans and classify their text.

## Analytics

- [Automobile Pricing and Exploratory Analysis](Analytics/automobile-exploratory-analysis/) — I investigated vehicle characteristics, pricing and correlations in an automobile dataset.

## Technical focus

Python · pandas · NumPy · scikit-learn · PyTorch · TensorFlow/Keras · spaCy · Matplotlib · seaborn

Each project has its own README explaining what I implemented, how to run the notebook, and the data it requires.
