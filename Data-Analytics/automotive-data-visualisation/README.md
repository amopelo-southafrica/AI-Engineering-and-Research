# Automotive Data Visualisation

## My analysis

I investigated the Cars93 dataset using histograms, manufacturer boxplots, scatter plots and mean-horsepower bar charts. I compared fuel efficiency, wheelbase, turning circle and vehicle categories.

## Reproduce my work

I used Python, pandas, Matplotlib and seaborn in [the notebook](automotive_visualisation.ipynb). The `Cars93.csv` source dataset is included in this folder. Install the required libraries and run the notebook cells in order.

I used descriptive visualisations to explore relationships rather than claim causal or predictive results.
