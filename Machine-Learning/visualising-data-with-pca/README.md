# Iris Principal Component Analysis

## Research question and approach

I used principal component analysis to transform standardized Iris measurements, inspected explained variance, visualized components and explored clustering in the reduced feature space.

## Implementation

I used pandas, numpy, seaborn, matplotlib, scikit-learn, scipy. My code and analysis are available in [iris-principal-component-analysis.ipynb](iris-principal-component-analysis.ipynb).

## Reproduce the project

Install Jupyter and the listed Python libraries. Run the cells in order.

## Implementation notes

The Iris dataset is loaded from scikit-learn; no external dataset file is needed.
