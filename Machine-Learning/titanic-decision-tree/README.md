# Titanic Decision Tree

## Research question and approach

I built a decision tree to classify passenger survival, transformed missing and categorical values, compared tree depths, and plotted training versus development accuracy.

## Implementation

I used pandas, numpy, matplotlib, scikit-learn. My code and analysis are available in [titanic-decision-tree.ipynb](titanic-decision-tree.ipynb).

## Reproduce the project

Install Jupyter and the listed Python libraries. Place `titanic.csv` in the notebook directory. Run the cells in order.

## Implementation notes

I corrected the missing development/test split variables in the published notebook to make the intended evaluation cells executable. The source dataset is not packaged in this repository.
