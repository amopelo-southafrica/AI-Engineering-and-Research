# Country Development Clustering with K-means

I scaled economic and development indicators, used inertia and silhouette scores to explore cluster counts, then visualised country groupings across child mortality, inflation and GDP per capita.

## Tools and implementation

I used pandas, numpy, matplotlib, scikit-learn in [my notebook](country_kmeans_clustering.ipynb).

## Reproduce my work

Install the listed packages, open Jupyter and run the notebook with `Country-data.csv` (included in this folder).

I corrected the last clustering cell to use the intended three-cluster model rather than the preceding loop variable.
