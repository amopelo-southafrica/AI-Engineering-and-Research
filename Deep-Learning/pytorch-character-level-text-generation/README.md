# Character-Level Text Generation with PyTorch

## What I developed

I created a character vocabulary, encoded text sequences, built a simple PyTorch recurrent neural network, and used the trained model to sample generated text character by character.

## Technical approach

I used pytorch, numpy, and documented the working code in [pytorch-character-level-text-generation.ipynb](pytorch-character-level-text-generation.ipynb).

## Reproduce my work

Install Jupyter and the listed libraries. Supply `input.txt` in the working directory. Open the notebook and run the cells in order.

## Notes

I left the source training code intact, including its hyperparameters; the input text file is not packaged with this project.
