# Neural Network Forward Propagation with NumPy

## What I developed

I implemented a two-layer feed-forward neural-network calculation using NumPy, weight matrices, bias terms and the sigmoid activation function, and applied it to sample player attributes.

## Technical approach

I used numpy, and documented the working code in [numpy-neural-network-forward-pass.ipynb](numpy-neural-network-forward-pass.ipynb).

## Reproduce my work

Install Jupyter and the listed libraries. Open the notebook and run the cells in order.

## Notes

The weights are randomly initialized and the network is not trained. The resulting score is a demonstration of the forward pass, not a validated player-quality predictor.
