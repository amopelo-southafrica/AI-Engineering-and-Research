# Backpropagation and Gradient Learning from Scratch

## What I developed

I implemented sigmoid activation, error calculation and gradient-based weight updates in NumPy. I trained the network on a small binary example and tracked the reduction in loss over iterations.

## Technical approach

I used numpy, matplotlib, and documented the working code in [numpy-backpropagation-gradient-learning.ipynb](numpy-backpropagation-gradient-learning.ipynb).

## Reproduce my work

Install Jupyter and the listed libraries. Open the notebook and run the cells in order.

## Notes

The notebook trains on a small example array defined in code. The learning curve illustrates the training loop rather than a generalization benchmark.
